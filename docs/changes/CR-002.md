# CR-002: Filter, Eigenschaften und 3D-Werkzeuge wie im HTML Model Viewer

## 1. Request

> Die Filter sollten wir der im HTML Viewer hinterlegte Filter funktionieren. Dabei muss auch ein erweiterter Filter einstellbar sein mit enthält / enthält nicht usw. (Was es eben alles gibt). Zudem sollten die Eigenschaften gerne im Viewer wie beim HTML Viewer wieder sein. Die Tabelle unten geht bis nach rechts. Der rechte Part mit den Elementdetails entfällt. So wirkt das Tool weniger voll, da diese nur beim anklicken eines Elements angezeigt werden. Der Viewer innendrin soll wirklich genauso aussehen wie der HTML Viewer (also Fokus / Filter / Färben innendrin. Beim anklicken dann ausblenden / isolieren und schneiden. Ausblenden und isolieren interagiert mit den filtern und der Tabelle. Nur schneiden nicht.

Normalized (after clarification, 2026-11-04, answers via the question dialog):

Each point is marked **[U]** (user answer, see §1a) or **[A]** (agent reading of the verbatim request).

1. **In-viewer toolbar as in the reference** (`html-modelviewer/ifc-viewer-builder.html`, cited `ref L<n>`) [U Q4]: round glass bar bottom centre with `Fokus`, `Filter`, `Färben` (ref L1306-1318 bar and filter button, L1509-1522 colour panel, CSS L1747-1752). `Fokus` replaces the 1.0.0 button `Ansicht einpassen` and fits the camera to the elements currently shown opaque (filter and hide/isolate applied; ghosts do not count) [U Q4 answer text "Fokus passt auf das an, was gerade sichtbar ist"]. Deviation from the reference, which fits whole models (ref L820-847, L879-881).

[U Q2: operators exactly as the reference; negation through the action `Ausblenden`.]
3. **Left filter sets stay** [U Q1] with counts and only-possible values (REQ-003/004). The in-viewer filter adds to them (AND). The reference chips `Kategorie` / `Datei` are not added (the left sets cover them) [A; deviation from the reference, see §8].
4. **Right details column removed** [A, verbatim request]. The table and the 3D view extend to the right edge; the left filter column keeps its full height.
5. **Properties as in the reference** [U Q7, Q8]: a floating panel top right in the 3D view (ref L310-321, L896-925), opened by a click in 3D or on a table row, closed with ×, `Esc` or a click on empty space. Header buttons `Ausblenden` / `Isolieren`. Row tools `Nach Wert filtern` (ticks the value in the matching left filter set, adding the set if missing) and `Farbe nach Wert`.
6. **Click menu in 3D as in the reference** [A, verbatim request; U Q7] (ref L1103-1123): `Ausblenden`, `Isolieren`, `Schneiden` at the click point.
7. **Ausblenden / Isolieren act as filters** [U Q3]: removed from 3D and table; `X von Y Elementen`, sums and CSV/Excel export follow; the filter area shows entries such as `Ausgeblendet: 3 Elemente` / `Isoliert: 2 Elemente`; `Alle Filter zurücksetzen` and the pills clear them. **Schneiden** affects only the 3D image (table, counts, export unchanged).
8. **Schneiden as in the reference** [U Q4]: section at the clicked face with handle and `Schnitt entfernen`; the X/Y/Z axis section is replaced.
9. **Färben as in the reference** [U Q4]: panel with property list, `Unterschiedliche Farben` / `Farbskala`, scale colours, legend in the panel (changes DEC-15 and TASK-005 L1; `mehrere Werte` and `(leer)` keep their colours).
10. **Ghost default stays on** [U Q5] (REQ-005-AC1; deviation from the reference, `xray = false`, ref L1184): filtered-out elements show as ghosts; the reference cube toggle `Ausgeblendete anzeigen` switches. Elements hidden or isolated away by the tools are always invisible.
11. **Saving** [U Q6]: filter rules and the search text are saved in the configuration and the viewer file; click-based hide / isolate are session-only. Old configurations and viewer files keep loading.

## 8. Decisions taken without asking (shown with this approval request and at the release gate)

- Rules combine with AND only (as the reference; OR exists within a left filter set).
- `Markieren` paints `#F08A87` and wins over `Färben`, below the selection (as the reference).
- `Freie Textsuche` / search field cover all properties of an element (as the reference, ref L435). If NFR-001 is not met with that at 30k elements, the trade-off (narrower scope or slower search) goes to the user as a question **before** a narrower scope is built.
- Rule matching as the reference: case-insensitive comparison on the displayed text (German number format as shown, e.g. `1,5`; units converted as displayed; booleans `Ja` / `Nein`); a multi-valued property matches if any value matches; an element without the property or with an empty value never matches (so `Isolieren` removes it, `Ausblenden` keeps it; ref L448-455). `(leer)` is not a matchable value.
- Hide/isolate details (named in the new DEC of the spec delta): a first `Isolieren` starts a new set, further clicks add to it (ref L1109-1117); `Ausblenden` and `Isolieren` combine (isolated minus hidden); on a group-row multi-selection they apply to all its elements; left filter-set counts and the DEC-14 zero-value rule are computed after hide/isolate; removing a model drops its elements from both sets.
- Deviations from the reference beyond the user's answers: no `Kategorie` / `Datei` chips in the panel (left sets cover them).
- Isolation on the session branch instead of `change/CR-002-<slug>` (environment allows pushes to the session branch only); tag `pre-CR-002` marks the baseline. Recorded in `docs/process-log.md`.
- No `Räume` 3D button (DEC-13 builder option stays).
- Configuration stays `calc-viewer-config/1` with optional fields.

These are shown to the user with the approval request of this CR and again at the release gate (the cycle-2 spec gate is an agent gate; the human gates are this CR approval and the 1.1.0 release).
