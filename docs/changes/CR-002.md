# CR-002: Filter, Eigenschaften und 3D-Werkzeuge wie im HTML Model Viewer

## 1. Request

> Die Filter sollten wir der im HTML Viewer hinterlegte Filter funktionieren. Dabei muss auch ein erweiterter Filter einstellbar sein mit enthält / enthält nicht usw. (Was es eben alles gibt). Zudem sollten die Eigenschaften gerne im Viewer wie beim HTML Viewer wieder sein. Die Tabelle unten geht bis nach rechts. Der rechte Part mit den Elementdetails entfällt. So wirkt das Tool weniger voll, da diese nur beim anklicken eines Elements angezeigt werden. Der Viewer innendrin soll wirklich genauso aussehen wie der HTML Viewer (also Fokus / Filter / Färben innendrin. Beim anklicken dann ausblenden / isolieren und schneiden. Ausblenden und isolieren interagiert mit den filtern und der Tabelle. Nur schneiden nicht.

Normalized (after clarification, 2026-11-04, answers via the question dialog):

1. **In-viewer toolbar as in the reference** (`html-modelviewer/ifc-viewer-builder.html`, cited `ref L<n>`): round glass bar bottom centre with `Fokus` (fit to what is currently visible), `Filter`, `Färben` (ref L1306-1318, CSS L1747-1752).
2. **In-viewer filter panel as in the reference** (ref L1319-1347): search `Suchen nach Objekten`, rule list, `+ Filter hinzufügen`, status `X von Y Objekten sichtbar`, `Zurücksetzen`; pill `Filter entfernen` with ghost toggle. Rule dialog `Filter bearbeiten` exactly as the reference (ref L654-740): Aktion `Isolieren` / `Ausblenden` / `Markieren` / `Freie Textsuche`, Eigenschaft with suggestions, Vergleich `Gleich` / `Beginnt mit` / `Endet mit` / `Enthält`, Wert with value suggestions; rules combine with AND (ref L1207-1215). **User decision: operators exactly as the reference** (negation through the action `Ausblenden`).
3. **Left filter sets stay** with counts and only-possible values (REQ-003/004). The in-viewer filter adds to them (AND). The reference chips `Kategorie` / `Datei` are not added (the left sets cover them).
4. **Right details column removed.** The table and the 3D view extend to the right edge; the left filter column keeps its full height.
5. **Properties as in the reference**: a floating panel top right in the 3D view (ref L310-321, L896-925), opened by a click in 3D or on a table row, closed with ×, `Esc` or a click on empty space. Header buttons `Ausblenden` / `Isolieren`. Row tools `Nach Wert filtern` (ticks the value in the matching left filter set, adding the set if missing) and `Farbe nach Wert`.
6. **Click menu in 3D as in the reference** (ref L1103-1123): `Ausblenden`, `Isolieren`, `Schneiden` at the click point.
7. **Ausblenden / Isolieren act as filters**: removed from 3D and table; `X von Y Elementen`, sums and CSV/Excel export follow; the filter area shows entries such as `Ausgeblendet: 3 Elemente` / `Isoliert: 2 Elemente`; `Alle Filter zurücksetzen` and the pills clear them. **Schneiden** affects only the 3D image (table, counts, export unchanged).
8. **Schneiden as in the reference**: section at the clicked face with handle and `Schnitt entfernen`; the X/Y/Z axis section is replaced.
9. **Färben as in the reference**: panel with property list, `Unterschiedliche Farben` / `Farbskala`, scale colours, legend in the panel (changes DEC-15 and TASK-005 L1; `mehrere Werte` and `(leer)` keep their colours).
10. **Ghost default stays on** (REQ-005-AC1): filtered-out elements show as ghosts; the reference cube toggle `Ausgeblendete anzeigen` switches. Elements hidden or isolated away by the tools are always invisible.
11. **Saving**: filter rules and the search text are saved in the configuration and the viewer file; click-based hide / isolate are session-only. Old configurations and viewer files keep loading.

- No `Räume` 3D button (DEC-13 builder option stays).
- Configuration stays `calc-viewer-config/1` with optional fields.
